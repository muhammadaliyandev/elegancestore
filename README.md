# Elegance Republic — Premium Pakistani Menswear Store

A full-stack **MERN** e-commerce store for premium Pakistani menswear — live and running on its own domain.

**🌐 Live site:** https://elegancerepublic.com

## Tech stack

| Layer    | Technology                          |
| -------- | ----------------------------------- |
| Frontend | React, Tailwind CSS                 |
| Backend  | Node.js, Express (REST API)         |
| Database | MongoDB + Mongoose                  |
| Media    | Cloudinary (product images / video) |
| Hosting  | Custom domain deployment (cPanel)   |

## Project structure

```
elegancestore/
  frontend/   # React + Tailwind storefront
  server/     # Express API + MongoDB models
```

## Run it locally

Backend:

```
cd server
npm install
# create a .env with your MONGO_URI (see the server code for the variables it reads)
npm run dev
```

Frontend (in a second terminal):

```
cd frontend
npm install
npm run dev
```
